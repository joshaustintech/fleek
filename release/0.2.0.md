Fleek 0.2.0 is a native macOS Apple Silicon CLI with explicitly selected Flay structural duplication and Reek ClassVariable checks. It includes the bounded Flay class and module method support added since v0.1.0, including literal optional positional defaults.

## Install

Download `fleek-0.2.0-macos-arm64.tar.gz` and its `.sha256` sidecar, verify the checksum, then extract the archive. The executable runs without Ruby, Flay, Reek, Spinel, a project checkout, or network access. It is ad hoc signed and not notarized.

## Coverage

Select `flay:StructuralDuplication`, `reek:ClassVariable`, or both with `--checks`. Fleek does not run analysis when checks are omitted. It accepts Ruby 4 source that need not compile as Spinel. Complete clean analysis exits 0, complete findings exit 2, and invalid or incomplete analysis exits 1.

Flay supports a bounded set of top-level, class, and direct module methods and documented expressions and control flow. Reek support is limited to ClassVariable and its documented configuration subset. Unsupported checks, syntax, settings, and formats are reported explicitly. The pinned Rails manifest preserves the reference score-48 Flay finding and fully analyzes the clean Reek ClassVariable check; Flay marks all 25 sources partial and exits 1 because other candidates remain unsupported. Full Rails Flay parity is not claimed.

## Evidence

The archive contract checks native arm64 architecture, libSystem-only linkage, notices, help/version, and clean/finding/incomplete examples with an empty `PATH`.
