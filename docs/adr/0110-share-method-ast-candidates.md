# ADR 0110: Share normalized AST candidates across method scopes

Flay compares method subtrees with structural hashes and node mass. Fleek's top-level method path instead compared statement tags, so calls with arguments were rejected and mass/identity behavior duplicated the class-method adapter.

Use the same bounded normalized AST tree and positional-parameter rules for top-level methods and class methods. Structural tree markers determine shape; supported node values and parameter names/defaults determine identical versus similar; the shared mass calculation counts AST nodes and excludes the same wrappers. Unsupported nodes still fail closed. This removes the separate statement-tag model and gives both method scopes one candidate algorithm.

Public contracts compare Flay 2.14.4 and Fleek for methods containing argument calls (mass/score 16), required parameters (mass/score 14), differing required arities (mass/score 12), optional parameters and differing defaults (mass/score 52), bounded if/else and unless control flow (mass/scores 62 and 16), local-variable writes and identity (mass/scores 38 and 16), boolean OR and AND expressions (mass/score 34 each), float and nil expressions (mass/scores 12 and 8), conditional returns (mass/score 44), and array/hash expressions (identical mass/scores 38/76 and 60/120).

Prism represents a range with a range node and endpoint nodes, while the reference mass for two identical method shapes is four lower than raw Prism node count. Apply a two-unit mass correction per range, and make both method and subtree mass calculations honor the complete signed adjustment. The public contract matches Flay's range mass/score 10. Prism stores `..` versus `...` in `PM_RANGE_FLAGS_EXCLUDE_END`; compare this flag so the shared tree reports those candidates as similar, matching Flay, instead of identical. Focused mutations reject missing range support, mass normalization, or operator comparison. Ruby 4 logical-and variants compare different operands and statement positions. Support remains bounded; other Flay method forms are tracked by ticket 22.
