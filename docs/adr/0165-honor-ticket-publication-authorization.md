# ADR 0165: Honor explicit authorization when publishing ticket breakdowns

Ticket breakdowns distinguish drafting from publication. Explicit current authorization or standing authorization that covers the ticket set and tracker permits publication without another approval round. A request for a draft alone permits only the draft; present it for review before publishing.

When authorized, the agent chooses sensible vertical slices and blocker edges without repeating quiz questions. Local tickets follow the canonical fields in `docs/agents/issue-tracker.md`. Publication never changes a parent issue.
