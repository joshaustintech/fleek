# ADR 0096: Compile mutation contracts at optimization level one

Mutation contracts run unchanged public assertions against a separately rebuilt mutant executable, so optimizing the contract harness at the production level adds compile cost without strengthening the mutated behavior check. Compile only these harness binaries with pinned Spinel `-O 1`; keep mutant builds at `-O 0` and all ordinary/native production gates at their existing settings. On `test/duplication_contract.rb`, default compile-plus-run took 23.75 seconds; `-O 1` took 6.55 seconds and produced the same passing result. PIT applies the same cost-control principle: select tests that cover each mutated bytecode location and avoid unrelated test execution; Fleek retains each full mapped public contract while caching only immutable reference results within a shard. References: [PIT FAQ](https://pitest.org/faq/), [PIT basic concepts](https://pitest.org/quickstart/basic_concepts/), and [PIT mutation systems](https://pitest.org/java_mutation_testing_systems/).
